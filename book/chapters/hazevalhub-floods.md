:::

## What the track will score

Surrogate models trained on physics-based flood simulations, which replace a hydrodynamic run
with a fast learned approximation. They are scored under a Common Task Framework: one task
specification, one hidden test set of simulations, one public scorer, and the same rules for
every entry.

## What it needs before it opens

Against [the nine rules](#the-nine-rules) on the hub page, the track opens only when it has a
written task specification (R1), a hidden test set (R2), a public scorer (R3) and a trivial
baseline (R4). Until then it scores nothing.
