- [ ] Added to **Slack**; joined thrust channel(s) + `#weekly-status` + `#general`
- [ ] Added to the **Google Calendar** + `gaia.hazlab@gmail.com` contact list
- [ ] Access to **UW SharedDrive** (working docs) — request from the coordinator
- [ ] Added to the **Roster Sheet** (Public + Private tabs) — [participant-roster.md](participant-roster.md)
- [ ] If opted in, added to the **Announce mailing list** — [mailing-list-setup.md](mailing-list-setup.md)
- [ ] (Funded) Listed in the private role↔person map (SharedDrive, not git)

## Expectations
- [ ] Read [00-kickoff-plan.md](../00-kickoff-plan.md) and
      [01-project-coordination.md](../01-project-coordination.md)
- [ ] Post to `#weekly-status` on the cadence (funded: ≥ monthly) using
      [weekly-status.md](weekly-status.md)
- [ ] Attend the Week-4 Project-Wide Update; optional office hours & forum

## FAIR & agentic conventions
- [ ] Repos use the shared template, tests, and permissive license (MIT/BSD-3)
- [ ] Every product gets a persistent ID (DOI/SWHID) + provenance YAML + RO-Crate
- [ ] Datasets are AI-ready (Zarr/TileDB/Parquet) with metadata
- [ ] Models get a versioned Hugging Face card + evaluator hooks
- [ ] Secrets/keys go in GitHub Secrets — never committed

- [ ] Portrait set (GitHub avatar by default) and one-line interest written
- [ ] Confirmed "list me on the public People page" preference
